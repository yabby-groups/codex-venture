<p lang="zh-CN">CrewAI 于 2026 年 11 月 24 日发布 1.15.45，新增将 HTML 或 Markdown 输出保存为 PDF 制品的功能。用 CrewAI 生成报告的团队可以直接把已有输出保存为便于分发的 PDF 文件。<a href="https://github.com/crewAIInc/crewAI/releases/tag/1.15.45">官方发布记录</a></p>

<p lang="en">CrewAI released 1.15.45 on November 24, 2026, adding the ability to save HTML or Markdown output as a PDF artifact. Teams that generate reports with CrewAI can save that output as a PDF for distribution. <a href="https://github.com/crewAIInc/crewAI/releases/tag/1.15.45">Official release notes</a></p>

<p lang="zh-CN">这个版本还移除了 <code>save_artifact</code> 工具结果的缓存。工作流再次调用该工具时，会执行保存操作。<a href="https://github.com/crewAIInc/crewAI/releases/tag/1.15.45">官方发布记录</a></p>

<p lang="en">The release also removes caching for results from the <code>save_artifact</code> tool. When a workflow invokes the tool again, it performs the save operation. <a href="https://github.com/crewAIInc/crewAI/releases/tag/1.15.45">Official release notes</a></p>
