<p lang="zh-CN">微软 Foundry 团队的 Amanda Foster 在 11 月 19 日介绍了面向 Microsoft 365 团队工作流的智能体构建能力。她列举了两种场景。在 Outlook 或 Teams 中，事件触发时可能没有已登录用户可供代理，而在群聊中，沿用某位成员的权限可能让其他成员看到他们原本无权访问的内容。<a href="https://devblogs.microsoft.com/foundry/build-trusted-autonomous-agents-for-your-team-with-microsoft-foundry">微软 Foundry 博客</a></p>

<p lang="en">On November 19, Amanda Foster of Microsoft Foundry introduced a way to build agents for team workflows in Microsoft 365. She highlighted two scenarios in Outlook and Teams. An event can trigger an agent when no user is signed in, and using one member’s permissions in a group chat can expose content to others who lack access. <a href="https://devblogs.microsoft.com/foundry/build-trusted-autonomous-agents-for-your-team-with-microsoft-foundry">Microsoft Foundry Blog</a></p>
