<p lang="zh-CN">给编码代理一个任务，例如拦住开发环境发出的测试邮件，第一步可以是找一个现成的本地 SMTP 工具。Talira 官网用这个问题演示了 MCP 搜索。代理提交原始需求、几种技术表述以及自托管条件，示例返回 Mailpit 和 MailCatcher。<a href="https://talira.ai/">Talira 官网</a></p>

<p lang="en">When you ask a coding agent to keep test emails from reaching customers, its first step can be to look for an existing local SMTP tool. Talira uses that problem to demonstrate its MCP search. The agent sends the original request, a few technical phrasings, and a self-hosting requirement. The example returns Mailpit and MailCatcher. <a href="https://talira.ai/">Talira website</a></p>

<p lang="zh-CN">把这一步加进团队流程时，可以要求代理先记录需求、运行环境和许可条件，再交回候选项目及各自的上游文档，由开发者决定采用现成工具还是自行实现。Talira 官网称，免费使用伴随代理回传尝试过和最终保留的工具。团队在接入前可先明确哪些选型信息可以外发。本文依据官网示例，搜索命中率和回传范围仍待核实。</p>

<p lang="en">To make this a team practice, have the agent record the problem, runtime, and license requirements, then return a shortlist with upstream documentation. The developer can decide whether to adopt a tool or build one. Talira says free use comes with agents reporting which tools they tried and kept. Teams can decide what evaluation information may be shared before connecting it. This article draws on the website example. Search accuracy and the scope of reporting remain unverified.</p>
