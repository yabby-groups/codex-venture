<p lang="zh-CN">three-dossier 将可旋转的 3D 产品视图、爆炸装配图和部件标注打包进一个独立 HTML 文件。按项目 README 的说明，接收方可直接在浏览器中离线打开仓库内的示例，适合把装配关系作为单个文件分享给评审人员。</p>

<p lang="en">three-dossier bundles a rotatable 3D product view, an exploded assembly, and part callouts into one self-contained HTML file. According to the project README, recipients can open the repository’s sample directly in a browser while offline, making it possible to share an interactive assembly view with reviewers as a single file.</p>

<p lang="zh-CN">文档列出了桌面和移动端布局、拖拽旋转、双指缩放，以及着色、泥模和 X 光三种显示模式。项目以 MIT 许可发布，打包后的 HTML 也保留了随附 three.js 代码的 MIT 许可文本。</p>

<p lang="en">The documentation lists desktop and mobile layouts, drag-to-orbit and pinch-to-zoom controls, and three display modes: shaded, clay, and X-ray. The project uses the MIT license, and the bundled HTML retains the MIT license text for the included three.js code.</p>
