<p lang="zh-CN">如果队友只发来一张成图，只要图里还嵌着工作流，就可以把它作为附件交给 ComfyUI Agent，取回生成这张图的节点流程。ComfyUI Frontend 于 2026 年 11 月 23 日发布的 v1.61.7 加入了这项功能，由 GitHub 用户 @christian-byrne 提交。<a href="https://github.com/Comfy-Org/ComfyUI_frontend/releases/tag/v1.61.7">发布说明</a></p>

<p lang="en">If a teammate sends you only the finished image, you can attach it to the ComfyUI agent and recover the node workflow that generated it, provided the workflow is still embedded in the file. The feature was contributed by GitHub user @christian-byrne and shipped in ComfyUI Frontend v1.61.7 on November 23, 2026. <a href="https://github.com/Comfy-Org/ComfyUI_frontend/releases/tag/v1.61.7">Release notes</a></p>

<p lang="zh-CN">需要接着调节点时，优先找保留工作流数据的原始文件。如果手头的副本已丢失这些数据，就请对方重发原图或单独分享工作流文件。</p>

<p lang="en">If you want to keep editing the nodes, start with the original file that retains the workflow data. If your copy has lost that data, ask for the original image or a separate workflow file.</p>
