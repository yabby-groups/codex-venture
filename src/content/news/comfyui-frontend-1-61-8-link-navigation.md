<p lang="zh-CN">ComfyUI 前端于 2026 年 11 月 24 日发布 v1.61.8。由 @shrimbly 提交的画布功能支持从节点端口跳到连线另一端。在大型工作流里，用户可以直接找到连接对象，省去手动沿线查找。<a href="https://github.com/Comfy-Org/ComfyUI_frontend/releases/tag/v1.61.8">官方发布记录</a></p>

<p lang="en">ComfyUI Frontend released v1.61.8 on November 24, 2026. A canvas change contributed by @shrimbly lets users jump from a node socket to the other end of a link, saving them from tracing it by hand in a large workflow. <a href="https://github.com/Comfy-Org/ComfyUI_frontend/releases/tag/v1.61.8">Official release notes</a></p>

<p lang="zh-CN">同一版本中，@christian-byrne 为 Ask Agent 的上下文加入错误目录 ID 和失败任务 ID。用户就失败任务求助时，助手可以利用这两个标识定位相关错误和任务。<a href="https://github.com/Comfy-Org/ComfyUI_frontend/releases/tag/v1.61.8">官方发布记录</a></p>

<p lang="en">In the same release, @christian-byrne added the error catalog ID and the failed job ID to Ask Agent’s context. When users ask for help with a failed job, the assistant can use those identifiers to refer to the relevant error and job. <a href="https://github.com/Comfy-Org/ComfyUI_frontend/releases/tag/v1.61.8">Official release notes</a></p>
