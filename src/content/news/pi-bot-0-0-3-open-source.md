<p lang="zh-CN">Pi Bot 在 2026 年 11 月 22 日随 0.0.3 版本以 Apache-2.0 许可证开源。项目 README 将它描述为一款基于 pi 智能体内核的本地优先应用。用户可以单独和一个有名字的代理对话，也可以把多个代理拉进同一个群聊分工。<a href="https://github.com/w01fb0ss/PiBot/releases/tag/v0.0.3">0.0.3 发布说明</a> · <a href="https://raw.githubusercontent.com/w01fb0ss/PiBot/HEAD/README.md">项目 README</a></p>

<p lang="en">Pi Bot went open source under the Apache 2.0 license with its 0.0.3 release on November 22, 2026. The project README describes it as a local-first app built on the pi agent kernel. Users can chat with one named agent or bring several into a group chat to divide the work. <a href="https://github.com/w01fb0ss/PiBot/releases/tag/v0.0.3">0.0.3 release notes</a> · <a href="https://raw.githubusercontent.com/w01fb0ss/PiBot/HEAD/README.md">Project README</a></p>

<p lang="zh-CN">整理本地项目资料时，可以在群聊里请一个代理拟定目录结构，再请另一个列出要移动或重命名的文件。用户可以先核对清单，再决定是否执行。README 说代理可以运行命令和编辑文件，项目判定为有风险的操作会等待用户批准。本文依据项目文档，分工场景仅作示例。</p>

<p lang="en">When organizing local project files, you could ask one agent to propose a folder structure and another to list the files it would move or rename. You can review that list before deciding whether to proceed. The README says agents can run commands and edit files, and that actions the app treats as risky wait for user approval. This example illustrates the documented features.</p>

<p lang="zh-CN">0.0.3 提供 Apple 芯片和 Intel 芯片版 macOS 安装包、Windows 10/11 x64 安装包、Linux x64 AppImage 和 Android APK。Mac 用户需要 macOS 13 Ventura 或更新版本。<a href="https://github.com/w01fb0ss/PiBot/releases/tag/v0.0.3">查看各平台下载</a></p>

<p lang="en">Version 0.0.3 offers macOS installers for Apple silicon and Intel Macs, a Windows 10/11 x64 installer, a Linux x64 AppImage, and an Android APK. The Mac app requires macOS 13 Ventura or later. <a href="https://github.com/w01fb0ss/PiBot/releases/tag/v0.0.3">View platform downloads</a></p>
