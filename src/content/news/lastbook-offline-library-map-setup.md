<p lang="zh-CN">准备一台离线工作电脑时，可以先选三个到现场可能要查的目标：一页手册、一个地址，以及一个必须回看出处的问题。David Díaz 对 Lastbook 1.1.17 的介绍把这些任务分别对应到资料库、州级地图和可选的本地模型。</p>

<p lang="en">When preparing a laptop for offline work, pick three things you might need in the field: a manual page, an address, and a question whose answer you need to trace to a source. David Díaz’s overview of Lastbook 1.1.17 maps those tasks to the library, the state map, and an optional local model.</p>

<p lang="zh-CN">首次设置时，按任务选择 Small、Medium 或 All 资料包。手头已有资料库目录或 ZIP 包时，也可以从本地导入。Díaz 列出的资料包括手册、PDF、视频和 ZIM 格式的离线百科。准备时可以先用关键词找一页实际会用到的手册，再打开原页核对。资料还少什么，可参考项目记录的缺项。</p>

<p lang="en">During setup, choose the Small, Medium, or All library pack based on the job. You can also import an existing local library folder or ZIP pack. Díaz lists manuals, PDFs, videos, and offline encyclopedias in ZIM format. To check your setup, search for a manual page you expect to use and open it to verify the content. The project’s gaps file records material the curators looked for and could not find.</p>

<p lang="zh-CN">地图设置关系到地址覆盖。应用有世界和美国底图，详细数据来自设置时选定的州。离线地址搜索也以该州为范围。出发前断开网络，用一个实际要去的地址检查覆盖。还要做资料问答时，再装可选的本地模型，试着打开答案所引用的库内页面。没有安装模型时，Chat 仍可检索相关页面。Díaz 的介绍仅在 Windows 下列出了语义搜索。</p>

<p lang="en">The map selection determines where offline address lookup is available. Lastbook includes world and U.S. basemaps, with detailed data for the state selected during setup. Offline address search covers that state. Before leaving, disconnect and try an address you actually plan to visit. If you also need question answering, install the optional local model and check that you can open the library pages it cites. Chat can still retrieve relevant pages without the model. Díaz lists semantic search only for Windows.</p>

<p lang="zh-CN">Díaz 的版本介绍列出受支持的 macOS 和 Windows 系统，以及面向 x86_64 Ubuntu 24.04 和 26.04 LTS 的软件包。上述核对步骤依据该介绍整理，实际覆盖和设备表现以读者对所选资料包与地图的断网检查为准。<a href="https://dev.to/dd8888/lastbook-1117-packages-offline-knowledge-maps-and-ai-44hm">Díaz 的 Lastbook 1.1.17 介绍</a></p>

<p lang="en">Díaz’s release overview lists supported macOS and Windows systems, plus packages for x86_64 Ubuntu 24.04 and 26.04 LTS. The preparation steps come from his overview. Use a disconnected check on your own device to confirm coverage for the library pack and map you selected. <a href="https://dev.to/dd8888/lastbook-1117-packages-offline-knowledge-maps-and-ai-44hm">Díaz’s Lastbook 1.1.17 overview</a></p>
