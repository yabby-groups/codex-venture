<p lang="zh-CN">Kakatu 于 2026 年 11 月 25 日在 Show HN 亮相。开发方介绍，这款应用读取 Claude Code CLI 已写入 Mac 的数据，把分散在多个终端里的会话状态集中到一个窗口。开发者可以查看哪些会话正在等待输入，也可以查看五小时和每周用量额度及其重置时间。</p>

<p lang="en">Kakatu appeared on Show HN on November 25, 2026. Its developer says the app reads data that the Claude Code CLI already writes on the Mac and brings session status from multiple terminals into one window. Developers can see which sessions are waiting for input and check their five-hour and weekly usage limits and reset times.</p>

<p lang="zh-CN">产品页还列出了按 MCP 服务器、插件和技能等项目拆分会话启动 token 开销的功能，方便用户定位哪些配置占用上下文。Kakatu 要求 macOS 14 或更新版本，测试期免费，官网标注一次性价格为 19 美元。</p>

<p lang="en">The product page also lists a breakdown of session startup tokens by items such as MCP servers, plugins, and skills, so users can see which parts of their setup consume context. Kakatu requires macOS 14 or later and is free during the beta. The site lists a one-time price of $19.</p>
