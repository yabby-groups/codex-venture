<p lang="zh-CN">Cursor 在 11 月 6 日发布了与编码 Agent 的实时语音通话。语音代理会把编码任务交给当前聊天中的 Agent，后者执行任务时，通话仍可继续。你可以问某个 diff 改了什么，或者查看一次运行的进度。编码 Agent 也会口头简报进度，并在完成后给出简短答复。</p>

<p lang="en">On November 6, Cursor introduced real-time voice calls with coding agents. The voice agent hands coding requests to the agent in the current chat, and the call stays open while that agent works. You can ask what changed in a diff or check the progress of a run. The coding agent also gives brief spoken updates and a short answer when it finishes.</p>

<p lang="zh-CN">通话支持 Agents Window、IDE、网页版和 iOS。在聊天里发起通话时，先等 Agent 空闲并清空输入框，再点击听写麦克风旁的波形按钮。iOS 用户也可以对 Siri 说“Hey Siri, call Cursor”，直接和一个新 Agent 开始通话。如果只想先把指令转成文字、检查后再发送，可以使用旁边的听写按钮。</p>

<p lang="en">Calls are available in the Agents Window, the IDE, on the web, and on iOS. To start a call from a chat, wait until the agent is idle and the input is empty, then click the waveform button next to the dictation microphone. On iOS, saying “Hey Siri, call Cursor” starts a call with a new agent. Use the dictation button if you want to review your spoken request as text before sending it.</p>

<p lang="zh-CN">Cursor 表示，通话由 Grok Voice 提供支持，开启 Privacy Mode 时，语音通话采用零数据保留。<a href="https://cursor.com/changelog/voice-chat">Cursor 更新日志</a></p>

<p lang="en">Cursor says calls are powered by Grok Voice and use zero data retention when Privacy Mode is enabled. <a href="https://cursor.com/changelog/voice-chat">Cursor changelog</a></p>
