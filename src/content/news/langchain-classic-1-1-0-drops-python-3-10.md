<p lang="zh-CN">LangChain 项目于 2026 年 11 月 23 日发布 langchain-classic 1.1.0。相较于 1.0.8，发布记录明确移除了该包对 Python 3.10 的支持。仍用 Python 3.10 运行 langchain-classic 的团队，需要先升级部署和 CI 环境，再采用 1.1.0。</p>

<p lang="en">The LangChain project released langchain-classic 1.1.0 on November 23, 2026. The release notes list the removal of Python 3.10 support among the changes since 1.0.8. Teams still running langchain-classic on Python 3.10 need to update their deployment and CI environments before adopting 1.1.0.</p>
