<p lang="zh-CN">Open WebUI 11 月 25 日发布的 v0.13.5 让自托管用户可以为项目文件夹选定一台电脑和一个工作目录。开发者可以在工作区的终端里跑测试，在浏览器标签页里试用应用，同时把聊天留在旁边。共用同一个文件夹的队友仍各自保留标签页和布局。<a href="https://github.com/open-webui/open-webui/releases/tag/v0.13.5">官方发布说明</a></p>

<p lang="en">Open WebUI v0.13.5, released on November 25, lets self-hosted users assign a computer and a working directory to a project folder. Developers can run tests in the workspace terminal and try the app in a browser tab with the chat still open alongside. Teammates sharing a folder each keep their own tabs and layout. <a href="https://github.com/open-webui/open-webui/releases/tag/v0.13.5">Official release notes</a></p>

<p lang="zh-CN">可以把测试入口或项目约定写进 AGENTS.md 或 CLAUDE.md。文件夹里的每个新对话都会读取项目说明，省去逐次交代。用 Open Terminal 0.18.0 或更新版本接入项目机器后，助手还可以使用可复用的项目技能，在终端运行检查，并在浏览器标签页查看结果。</p>

<p lang="en">Developers can put test entry points or project conventions in AGENTS.md or CLAUDE.md. Every new chat in the folder reads the project instructions, so there’s no need to restate them. With the project machine connected through Open Terminal 0.18.0 or later, the assistant can also use reusable project skills, run checks in the terminal, and inspect the results in the browser tab.</p>
