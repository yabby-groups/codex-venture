<p lang="zh-CN">MCP Registry 于 11 月 23 日发布了 MakeAIVideo 的 1.7.0 登记记录，目前标为有效。按项目文档，支持 MCP 的客户端可以提交提示词或脚本并取得成品 MP4，也可以向已连接的 TikTok、Instagram Reels 和 YouTube Shorts 账号发帖或安排定时发布。</p>

<p lang="en">The MCP Registry published MakeAIVideo’s 1.7.0 entry on November 23 and lists it as active. According to the project documentation, MCP clients can submit a prompt or script and receive a finished MP4. They can also publish or schedule posts to connected TikTok, Instagram Reels, and YouTube Shorts accounts.</p>

<p lang="zh-CN">项目提供两种连接方式。托管端点使用 Streamable HTTP 和 OAuth 登录，本地 npm 包通过 stdio 连接并要求 MakeAIVideo API 密钥。登记版本为 1.7.0，同一记录列出的本地包版本为 1.2.0。社交发布功能的适用范围是已连接的账号。</p>

<p lang="en">The project documents two connection options. The hosted endpoint uses Streamable HTTP with OAuth sign-in. The local npm package connects over stdio and requires a MakeAIVideo API key. The registry entry is version 1.7.0 and lists version 1.2.0 for the local package. Social publishing is available for connected accounts.</p>
