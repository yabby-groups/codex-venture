<h2><span lang="zh-CN">版本变化</span><span lang="en">What changed</span></h2>

<p lang="zh-CN">11 月 22 日（北京时间），qwen-code 发布 v0.28.4。Qwen Code 0.28.4 的本地守护进程模式新增工作区工件页面，支持逐步扫描和流式更新。</p>

<p lang="en">qwen-code published v0.28.4 on November 22 (China Standard Time). The local daemon mode in Qwen Code 0.28.4 adds a workspace artifact page with progressive scanning and streaming updates.</p>

<h2><span lang="zh-CN">适用场景</span><span lang="en">Where it matters</span></h2>

<p lang="zh-CN">用 Web Shell 查看长期任务产物时，可以在一处浏览工作区工件。另有移动端布局调整，运行时状态目录也会在创建进程时使用仅所有者可访问的权限。</p>

<p lang="en">The Web Shell gives users a single view of workspace artifacts from long-running tasks. The release also adjusts mobile layouts and creates the local runtime state directory with owner-private permissions.</p>

<h2><span lang="zh-CN">获取与验证</span><span lang="en">Availability and validation</span></h2>

<p lang="zh-CN">从版本页获取更新。工件库针对本地守护进程模式，使用普通 CLI 的团队可单独评估是否需要 Web Shell。</p>

<p lang="en">Get the update from the release page. The artifact library applies to local daemon mode. Teams using the standalone CLI can assess whether they need the Web Shell.</p>
