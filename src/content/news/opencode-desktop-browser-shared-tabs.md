<p lang="zh-CN">测试登录后的页面时，开发者可以在 OpenCode 的桌面浏览器中打开自有测试站点，把当前页面交给 Agent 查看或操作，再回到同一个标签页检查结果。OpenCode 在 2026 年 11 月 23 日发布的 v2.4.0 中加入了这个内置浏览器。<a href="https://github.com/anomalyco/opencode/releases/tag/v2.4.0">发布说明</a></p>

<p lang="en">When testing a page that requires sign-in, developers can open their own test site in OpenCode’s desktop browser, let the agent inspect or interact with the page, and then check the result in the same tab. The built-in browser shipped in OpenCode v2.4.0 on November 23, 2026. <a href="https://github.com/anomalyco/opencode/releases/tag/v2.4.0">Release notes</a></p>

<p lang="zh-CN">桌面版支持从 Chrome、Edge、Firefox 或 Safari 导入登录状态和浏览历史。内置浏览器使用持久化配置，重启应用后仍会保留标签页，方便开发者接着检查之前打开的页面。</p>

<p lang="en">The desktop app can import sign-in state and browsing history from Chrome, Edge, Firefox, or Safari. Its browser uses a persistent profile, so developers can return to their open tabs after restarting the app.</p>
