<h2><span lang="zh-CN">项目用途</span><span lang="en">What it does</span></h2>

<p lang="zh-CN">Crawl4AI 提供基于浏览器的网页采集，可保留标题、表格和代码，并按内容条件过滤页面正文。</p>

<p lang="en">Crawl4AI collects pages in a browser and can preserve headings, tables and code while filtering page content.</p>

<h2><span lang="zh-CN">适用场景</span><span lang="en">Where to use it</span></h2>

<p lang="zh-CN">对文档检索任务，可把导航、页脚和正文分别检查，评估过滤后有没有遗漏参数表和示例。动态页面仍会受渲染时间、会话和访问权限影响。</p>

<p lang="en">For documentation retrieval, inspect navigation, footer and body content separately to see whether filtering drops parameter tables or examples. Dynamic pages remain sensitive to rendering time, session state and access permissions.</p>

<h2><span lang="zh-CN">获取与项目状态</span><span lang="en">Getting started and project status</span></h2>

<p lang="zh-CN">仓库提供 Python、CLI 和 Docker 的自托管入口。先选允许访问的页面做抽取验证。 仓库创建于 2024-05-09，GitHub API 在 11 月 24 日记录的最近推送日期为 2026-11-23（UTC）。许可证为 Apache-2.0。</p>

<p lang="en">The repository documents self-hosted Python, CLI and Docker paths. Start with pages you have permission to access. The repository was created on 2024-05-09. On November 24, the GitHub API reported 2026-11-23 as its latest push date (UTC). The license is Apache-2.0.</p>
