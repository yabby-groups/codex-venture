<p lang="zh-CN">用 Copilot 做完首页再做定价页时，可以让两页共用一份 DESIGN.md。UXKIN 在 2026 年 11 月 1 日发布到 Open VSX 的 Website Design 1.0.0 提供了这套流程。按 UXKIN 的文档，web-design-system 技能会从同类网站提炼配色及其用途、字体、间距和组件规则，把这些决定写进 DESIGN.md，并同步到项目的设计令牌中。<a href="https://open-vsx.org/api/uxkin/website-design">Open VSX 版本记录</a></p>

<p lang="en">When you build a homepage and then a pricing page with Copilot, both can follow the same DESIGN.md. UXKIN’s Website Design 1.0.0, published on Open VSX on November 1, 2026, provides a workflow for doing that. According to UXKIN’s documentation, the web-design-system skill draws on comparable sites for colors and their roles, typography, spacing, and component rules, then records those decisions in DESIGN.md and the project’s design tokens. <a href="https://open-vsx.org/api/uxkin/website-design">Open VSX version record</a></p>

<p lang="zh-CN">团队可以先审阅这份文件，再让 landing-page 技能按同一套规则制作首页和定价页。UXKIN 的文档把手机、平板和桌面布局列入建页检查，另提供 web-review 技能，把现有页面的问题按修复优先级排序。三项技能可独立使用，无需 UXKIN 账号。若要通过可选的 MCP 服务搜索 UXKIN 托管的参考库，则需要 UXKIN 套餐。本文依据发布记录和官方文档撰写，未运行扩展。<a href="https://open-vsx.org/api/uxkin/website-design/1.0.0/file/readme.md">UXKIN 扩展文档</a></p>

<p lang="en">A team can review the file before asking the landing-page skill to build the homepage and pricing page from the same rules. UXKIN’s documentation includes phone, tablet, and desktop layout checks in the page-building workflow. A separate web-review skill ranks issues on existing pages by what to fix first. The three skills can run on their own without a UXKIN account. Searching UXKIN’s hosted reference library through the optional MCP service requires a UXKIN plan. This article is based on the release record and official documentation. We did not run the extension. <a href="https://open-vsx.org/api/uxkin/website-design/1.0.0/file/readme.md">UXKIN extension documentation</a></p>
