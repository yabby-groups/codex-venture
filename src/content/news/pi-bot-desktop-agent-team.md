<h2><span lang="zh-CN">项目用途</span><span lang="en">What it does</span></h2>

<p lang="zh-CN">Pi Bot 是基于 pi 的桌面 Agent 应用，可以为不同角色配置模型、权限和技能，再由群聊协调器分配工作。</p>

<p lang="en">Pi Bot is a desktop agent app built on pi. It lets users configure models, permissions and skills by role and assign work through a group coordinator.</p>

<h2><span lang="zh-CN">适用场景</span><span lang="en">Where to use it</span></h2>

<p lang="zh-CN">适合在选定文件夹里尝试分工，比如一名 Agent 读项目资料，另一名整理交付物。项目文档列出工具审批与操作日志。使用远程模型时，发给模型的提示词会离开设备。</p>

<p lang="en">Try it on a selected folder, with one agent reading project material and another preparing a deliverable. The docs describe tool approvals and audit logs. Prompts sent to a remote model leave the device.</p>

<p lang="zh-CN">从仓库进入官网下载安装。开发版需要仓库指定的 Node 版本和 pnpm 12。 仓库创建于 2026-11-21，GitHub API 在 11 月 24 日记录的最近推送日期为 2026-11-24（UTC）。许可证为 Apache-2.0。</p>

<p lang="en">Follow the repository link to download the app. Source builds require the repository’s Node version and pnpm 12. The repository was created on 2026-11-21. On November 24, the GitHub API reported 2026-11-24 as its latest push date (UTC). The license is Apache-2.0.</p>
