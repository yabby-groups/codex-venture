<p lang="zh-CN">OpenHands 于 2026 年 11 月 25 日发布 v1.46.0。曾向团队组织共享会话的用户现在可以查看已共享的会话列表，并撤销共享。发布记录将这项改动归功于 @hieptl。</p>

<p lang="en">OpenHands released v1.46.0 on November 25, 2026. Users who have shared conversations with a team organization can now see which conversations they shared and revoke access. The release notes credit @hieptl for the change.</p>

<p lang="zh-CN">同一版本还为自动化的 Git Sync 增加了一个开关，让使用 Git 同步的用户可以把自动化的启用状态保留在本地。发布记录将这项改动也归功于 @hieptl，并将新增的反馈按钮和提交流程归功于 @DevinVinson。<a href="https://github.com/OpenHands/OpenHands/releases/tag/v1.46.0">官方发布记录</a></p>

<p lang="en">The same release adds a Git Sync switch that lets users keep automation activation settings local. The release notes also credit @hieptl for that switch and @DevinVinson for the new feedback button and submission flow. <a href="https://github.com/OpenHands/OpenHands/releases/tag/v1.46.0">Official release notes</a></p>
