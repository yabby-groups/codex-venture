<p lang="zh-CN">如果 Codex 或 Claude Code 已经装在工作站上，Cloveric 的 TaroBird 提供了一个从 iPhone 与这些代理对话的入口。按项目 README 的流程，先在桌面应用里把工作站设为主机，再用这台机器上已经安装的引擎创建 Bot。项目文档同时提供了 iOS 客户端入口。</p>

<p lang="en">If Codex or Claude Code is already installed on your workstation, Cloveric’s TaroBird offers a way to chat with those agents from an iPhone. The project README describes setting up the workstation as a host in the desktop app, then creating a Bot with an engine already installed on that machine. The documentation also links to the iOS client.</p>

<p lang="zh-CN">采用前要区分两件事：从手机与主机上的代理对话，以及接管一条已经在终端里开始的会话。现有 README 摘录支持前一种用法，尚无法确认已有会话的接续条件。Cloveric 还注明 Windows 安装器尚未签名。</p>

<p lang="en">Before adopting it, distinguish chatting with a host-side agent from taking over a session already started in a terminal. The available README excerpt documents the first use case and leaves the conditions for resuming existing sessions unclear. Cloveric also says the Windows installer is currently unsigned.</p>
