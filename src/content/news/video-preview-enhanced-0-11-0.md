<p lang="zh-CN">Open VSX 于 2026 年 11 月 24 日（UTC）收录了 Video Preview Enhanced 0.11.0。发布者文档显示，扩展可在 VS Code 中播放本地、Remote-SSH 和 WSL 环境里的视频。开发者可以把同一段素材的多个渲染结果放在一起，同步播放并逐帧比较，最多可同时对照 16 段视频。<a href="https://open-vsx.org/api/gordon-vidal/video-preview-enhanced/0.11.0/file/readme.md">0.11.0 版说明</a></p>

<p lang="en">Open VSX listed Video Preview Enhanced 0.11.0 on November 24, 2026 (UTC). The publisher documents video playback in VS Code for local, Remote-SSH, and WSL sessions. Developers can play up to 16 clips in sync and step through them frame by frame to compare renders of the same footage. <a href="https://open-vsx.org/api/gordon-vidal/video-preview-enhanced/0.11.0/file/readme.md">Version 0.11.0 documentation</a></p>

<p lang="zh-CN">该版本的扩展元数据要求 VS Code 1.82.0 或以上。发布者称基础播放无需另装组件，可选的便携版 FFmpeg 无需管理员权限。通过 Remote-SSH 预览时，较重的视频可在 SSH 主机上转码。本文所述功能以 0.11.0 版文档为准。<a href="https://open-vsx.org/extension/gordon-vidal/video-preview-enhanced">Open VSX 扩展页面</a></p>

<p lang="en">The extension metadata requires VS Code 1.82.0 or later. The publisher says basic playback needs no additional components and that the optional portable FFmpeg setup needs no administrator privileges. Larger videos can be transcoded on the SSH host during remote preview. This coverage reflects the documentation for version 0.11.0. <a href="https://open-vsx.org/extension/gordon-vidal/video-preview-enhanced">Open VSX extension listing</a></p>
