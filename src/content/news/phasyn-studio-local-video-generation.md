<p lang="zh-CN">Phasyn Studio 的项目文档将它定位为一套在自己电脑上运行的生成工具，可制作带声音的短视频和静态图片。据维护者介绍，安装器会先根据设备生成一份方案，列出各项功能可使用的显卡、所需模型及其许可，用户确认后才会安装并启动。</p>

<p lang="en">The Phasyn Studio maintainers describe it as a tool for generating short videos with sound and still images on your own computer. According to the project README, the installer checks the machine and presents a plan showing which graphics card each feature can use, which models are needed, and what licenses apply. It installs and starts the software after the user approves the plan.</p>

<p lang="zh-CN">工作室代码采用 Apache 2.0 许可。模型需另行获取，并各自适用独立条款。项目 README 以 Qwen-Image 2.1 为例，注明该模型仅限非商业用途。</p>

<p lang="en">The studio code is licensed under Apache 2.0. Models are obtained separately and come with their own terms. The project README lists Qwen-Image 2.1 as an example and specifies that it is for noncommercial use only.</p>
