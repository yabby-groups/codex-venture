<p lang="zh-CN">Unsloth 在 11 月 23 日发布的 Desktop v0.1.923-beta 中加入了图片翻译，并将译文绘制在图上。处理外语界面截图时，可以一边读译文，一边对照它所指的按钮、菜单或提示框。<a href="https://github.com/unslothai/unsloth/releases/tag/v0.1.923-beta">Unsloth 发布说明</a></p>

<p lang="en">Unsloth added image translation in its November 23 Desktop release, v0.1.923-beta. The app draws the translation on the image, so readers can see which button, menu, or dialog the translated text refers to in a screenshot. <a href="https://github.com/unslothai/unsloth/releases/tag/v0.1.923-beta">Unsloth release notes</a></p>

<p lang="zh-CN">如果手头只有一张外语截图，可以用图片翻译在画面中查看译文。如果手头有字幕或音频原素材，可以按素材类型使用同一测试版新增的字幕或音频翻译。发布说明只明确了图片译文如何呈现。</p>

<p lang="en">If you have a screenshot, image translation lets you read the translated text in context. If you have the original subtitles or audio, the same beta adds translation for those formats. The release notes specify the output presentation only for images.</p>
