<p lang="zh-CN">同时用 Codex 修一个项目、用 Claude Code 处理另一个项目时，Paradev 提供一个按项目归拢会话的桌面工作区。项目 README 展示了多个代理会话并行工作的界面，并列出 macOS 和 Linux 的下载入口。</p>

<p lang="en">If you use Codex to fix one project while Claude Code works on another, Paradev gives you a desktop workspace that groups the sessions by project. The project README shows several agent sessions running in parallel and links to macOS and Linux downloads.</p>

<p lang="zh-CN">按 README 的套餐说明，只在电脑上管理会话，可以从包含本地工作区、桌面端和 CLI 的免费层开始。如果需要离开电脑后用手机继续处理会话，就要把 Pro 纳入预算。远程访问、iOS 和 Android 应用、自动化以及 Linear 和 Slack 集成都列在 Pro 层。</p>

<p lang="en">According to the README, the free plan includes local workspaces, the desktop app, and the CLI, so it covers getting started with desktop session management. If you need to pick up sessions from your phone while away from your computer, budget for Pro. That tier lists remote access, the iOS and Android apps, automation, and Linear and Slack integrations.</p>
