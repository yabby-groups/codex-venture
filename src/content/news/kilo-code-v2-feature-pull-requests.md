<p lang="zh-CN">准备给 Kilo Code 提交新功能的开发者，需要把拉取请求的目标分支设为 <code>v2</code>。截至 2026 年 11 月 27 日，项目 README 已明确这一要求。<a href="https://github.com/Kilo-Org/kilocode">项目仓库</a></p>

<p lang="en">Developers contributing a new feature to Kilo Code should set <code>v2</code> as the base branch of their pull request. The project README documented this requirement as of November 27, 2026. <a href="https://github.com/Kilo-Org/kilocode">Project repository</a></p>

<p lang="zh-CN">如果提交的是当前发行版的错误修复，README 仍允许以 <code>main</code> 为目标分支。</p>

<p lang="en">For bug fixes to the current release, the README still allows contributors to target <code>main</code>.</p>
