<p lang="zh-CN">GitHub 和微软在 Codename MDASH 试点中，将数千条初始 AI 发现筛成 99 份经过核验、附有修复建议的私密报告，提交给六个开源项目。Ashley Wolf 和 Gregg Cochran 在 11 月 17 日发布的 GitHub 博文中写道，截至发文，维护者已修复报告中超过一半的问题。<a href="https://github.blog/open-source/maintainers/maintainers-dont-need-more-ai-bug-reports-they-need-fixes">GitHub 试点报告</a></p>

<p lang="en">In the Codename MDASH pilot, GitHub and Microsoft narrowed thousands of initial AI findings to 99 verified private reports with suggested fixes for six open-source projects. In a November 17 GitHub post, Ashley Wolf and Gregg Cochran wrote that maintainers had fixed more than half the reported issues by publication. <a href="https://github.blog/open-source/maintainers/maintainers-dont-need-more-ai-bug-reports-they-need-fixes">GitHub pilot report</a></p>

<p lang="zh-CN">维护者如果要为贡献者约定 AI 辅助安全报告的接收标准，可以把核验和修复建议放在提交环节，让维护者收到报告时就有材料判断下一步。试点数据由组织方公布，修复进度只反映这六个项目在发文时的情况。</p>

<p lang="en">Maintainers setting standards for AI-assisted security reports can ask contributors to verify findings and include proposed fixes before submission. That gives maintainers material to assess when a report arrives. The organizers published the figures, and the repair progress covers those six projects as of publication.</p>
