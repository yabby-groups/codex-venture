<p lang="zh-CN">Unsloth 在 11 月 16 日的 v0.1.918-beta 发布说明中介绍了桌面端的 Computer Use 测试功能。它覆盖 macOS、Windows 和 Linux，获准后，模型可以读取屏幕画面，并通过鼠标和键盘操作桌面应用。<a href="https://github.com/unslothai/unsloth/releases/tag/v0.1.918-beta">官方发布说明</a></p>

<p lang="en">Unsloth introduced its Computer Use beta in the November 16 release notes for v0.1.918-beta. On macOS, Windows, and Linux, authorized models can view the screen and use the mouse and keyboard to interact with desktop apps. <a href="https://github.com/unslothai/unsloth/releases/tag/v0.1.918-beta">Official release notes</a></p>

<p lang="zh-CN">功能默认关闭，应用提供权限控制。试用前先确认会话使用的是本地视觉模型，还是已经连接的模型提供商，再查看屏幕访问和桌面操作的授权设置。两种模型来源都在发布说明列出的适用范围内。</p>

<p lang="en">The feature is off by default and comes with permission controls. Before trying it, check whether the session uses a local vision model or a connected model provider, then review the permissions for screen access and desktop interaction. The release notes list both model sources as supported.</p>
