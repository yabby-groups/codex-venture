<h2><span lang="zh-CN">本地推理</span><span lang="en">Local inference</span></h2>

<p lang="zh-CN">mistral.rs 提供 CLI、服务和 SDK。支持的 Metal 模型从 0.9.5 起默认启用分页注意力。 <a href="https://codex-venture.com/news/mistralrs-metal-local-inference/">站内报道</a></p>

<p lang="en">mistral.rs offers a CLI, server and SDK. Since 0.9.5, paged attention is the default for supported Metal models. <a href="https://codex-venture.com/news/mistralrs-metal-local-inference/">Read the story</a></p>

<h2><span lang="zh-CN">桌面多 Agent</span><span lang="en">Desktop multi-agent workflows</span></h2>

<p lang="zh-CN">11 月 21 日创建的 Pi Bot 可以给每个角色设置独立权限，再把它们放在同一个会话里协作。 <a href="https://codex-venture.com/news/pi-bot-desktop-agent-team/">站内报道</a></p>

<p lang="en">Pi Bot, whose repository was created November 21, gives each role its own permissions and puts them in one conversation to collaborate. <a href="https://codex-venture.com/news/pi-bot-desktop-agent-team/">Read the story</a></p>

<h2><span lang="zh-CN">离线听写</span><span lang="en">Offline dictation</span></h2>

<p lang="zh-CN">Handy 把快捷键、语音识别和粘贴组合起来，适合用自己的术语测试短文听写。 <a href="https://codex-venture.com/news/handy-offline-dictation/">站内报道</a></p>

<p lang="en">Handy combines a hotkey, speech recognition and pasting. Try it on short passages that contain your own terminology. <a href="https://codex-venture.com/news/handy-offline-dictation/">Read the story</a></p>

<h2><span lang="zh-CN">知识库检索</span><span lang="en">Knowledge-base retrieval</span></h2>

<p lang="zh-CN">RAGFlow 可从 PDF 解析与入库开始搭一条完整检索链路。测试时可追踪回答是否找到了正确的原文段落。 <a href="https://codex-venture.com/news/ragflow-document-retrieval/">站内报道</a></p>

<p lang="en">RAGFlow covers a retrieval pipeline from PDF parsing through ingestion. In evaluation, check whether an answer retrieves the right source passage. <a href="https://codex-venture.com/news/ragflow-document-retrieval/">Read the story</a></p>

<h2><span lang="zh-CN">网页资料整理</span><span lang="en">Web document extraction</span></h2>

<p lang="zh-CN">Crawl4AI 可将网页转换为保留标题、表格与代码的 Markdown，方便给检索系统准备输入。 <a href="https://codex-venture.com/news/crawl4ai-browser-markdown-extraction/">站内报道</a></p>

<p lang="en">Crawl4AI converts pages into Markdown with headings, tables and code, preparing input for retrieval systems. <a href="https://codex-venture.com/news/crawl4ai-browser-markdown-extraction/">Read the story</a></p>
