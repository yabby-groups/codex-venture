<p lang="zh-CN">JetBrains 在 GoLand 博客上发布了 Go by GoLand 的免费公开 Beta。公告作者 Sergey Larionov 写道，团队希望把部分 GoLand 能力带到 IntelliJ 平台之外，并在预览阶段收集性能反馈和功能需求。使用 Cursor 或 VS Code 的 Go 开发者可以在现有编辑器里试用这些能力。</p>

<p lang="en">JetBrains announced a free public beta of Go by GoLand on the GoLand blog. Announcement author Sergey Larionov says the team wants to bring some GoLand capabilities beyond the IntelliJ Platform and use the preview to collect performance feedback and feature requests. Go developers using Cursor or VS Code can try those capabilities in their existing editor.</p>

<p lang="zh-CN">扩展通过语言服务器协议（LSP）和调试适配器协议（DAP）向编辑器提供 Go 编辑与调试能力。公开 Beta 只覆盖 GoLand 的部分功能。公告摘录未列出完整的功能和兼容性清单，实际使用范围以这次预览为限。<a href="https://blog.jetbrains.com/go/2026/11/25/go-by-goland-public-preview">JetBrains 公告</a></p>

<p lang="en">The extension uses the Language Server Protocol (LSP) and Debug Adapter Protocol (DAP) to provide Go editing and debugging capabilities. The public beta covers a subset of GoLand features, and the announcement excerpt does not include a complete feature or compatibility list. <a href="https://blog.jetbrains.com/go/2026/11/25/go-by-goland-public-preview">JetBrains announcement</a></p>
