<h2><span lang="zh-CN">Claude Code 扩大终端 Code Mode 的支持范围</span><span lang="en">Claude Code expands terminal Code Mode support</span></h2>

<p lang="zh-CN">Claude Code 2.1.331 在 Amazon Bedrock、Google Cloud Agent Platform、Microsoft Foundry 和 AWS 上的 Claude Platform 增加了终端 Code Mode 支持。在这些平台使用 Claude Code 的团队可以从现有终端环境开始评估这项功能。<a href="https://github.com/anthropics/claude-code/releases/tag/v2.1.331">原始发布说明</a></p>

<p lang="en">Claude Code 2.1.331 adds terminal Code Mode support on Amazon Bedrock, Google Cloud’s Agent Platform, Microsoft Foundry and Claude Platform on AWS. Teams using Claude Code on those platforms can evaluate the feature in their existing terminal environments. <a href="https://github.com/anthropics/claude-code/releases/tag/v2.1.331">Release notes</a></p>

<h2><span lang="zh-CN">Codex CLI 修复非交互会话的恢复行为</span><span lang="en">Codex CLI fixes recovery for non-interactive sessions</span></h2>

<p lang="zh-CN">Codex CLI 0.172.0 修复了 codex exec resume 恢复沙箱、工作目录和可写路径的行为，同时允许从线程链接打开已保存的会话。自动化维护者可以据此检查续跑任务的目录和写入范围。<a href="https://github.com/openai/codex/releases/tag/rust-v0.172.0">原始发布说明</a></p>

<p lang="en">Codex CLI 0.172.0 fixes how codex exec resume restores sandbox settings, working directories and writable roots. It also opens saved sessions from thread links. Automation maintainers can use the release notes to check where resumed tasks run and which paths they can write to. <a href="https://github.com/openai/codex/releases/tag/rust-v0.172.0">Release notes</a></p>

<h2><span lang="zh-CN">OpenClaw 改进网关重启后的会话恢复</span><span lang="en">OpenClaw improves conversation recovery after Gateway restarts</span></h2>

<p lang="zh-CN">OpenClaw v2026.11.7 的发布说明称，网关重启后可恢复中断的回复和子任务结果。这对运行长任务的团队尤其相关，因为维护重启可能发生在子任务仍未完成时。<a href="https://github.com/openclaw/openclaw/releases/tag/v2026.11.7">原始发布说明</a></p>

<p lang="en">The OpenClaw v2026.11.7 release notes say interrupted replies and child-task results can be recovered after a Gateway restart. This is especially relevant to teams running long jobs, where a maintenance restart may occur while a child task is still pending. <a href="https://github.com/openclaw/openclaw/releases/tag/v2026.11.7">Release notes</a></p>
