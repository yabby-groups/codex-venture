<h2><span lang="zh-CN">GitHub 将调整 Copilot 代码审查的默认计费</span><span lang="en">GitHub will change the default billing for Copilot code review</span></h2>

<p lang="zh-CN">GitHub 于 11 月 25 日宣布，自 12 月 30 日起，尚未保存计费选项且符合条件的 Copilot Business 和 Enterprise 客户，其持有 Copilot 许可证的成员发起的代码审查将默认计入仓库所属组织的账单。希望继续使用成员额度的管理员可提前在 Copilot 策略中选择 Member。组织计费要求启用 AI Credits 付费用量，并可能增加组织支出。<a href="https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization">GitHub 公告</a></p>

<p lang="en">GitHub announced on November 25 that starting December 30, eligible Copilot Business and Enterprise customers with no saved billing choice will have code reviews requested by licensed members billed to the organization that owns the repository. Administrators who want to keep using members’ entitlements can select Member in the Copilot policy before then. Organization billing requires paid AI Credits usage and can increase the organization’s spending. <a href="https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization">GitHub announcement</a></p>

<h2><span lang="zh-CN">Cloudflare 为网站自动建立代理可发现的搜索索引</span><span lang="en">Cloudflare automates site indexing and search discovery for agents</span></h2>

<p lang="zh-CN">Celso Martinho、Gabriel Massadas 和 Nelson Duarte 于 11 月 25 日介绍了 Search for Agents。站点管理员在 Cloudflare 控制台按站点启用后，Cloudflare 会创建 AI Search 实例、抓取并索引网站内容，并在站点自己的域名下提供代理可发现的搜索 API。免费套餐也可启用，有用量限制。<a href="https://blog.cloudflare.com/search-for-agents">Cloudflare 发布说明</a></p>

<p lang="en">Celso Martinho, Gabriel Massadas, and Nelson Duarte introduced Search for Agents on November 25. Once an administrator enables it for a site in the Cloudflare dashboard, Cloudflare creates an AI Search instance, crawls and indexes the site, and exposes a search API that agents can discover on the site’s own domain. The feature is available on the Free plan with limits. <a href="https://blog.cloudflare.com/search-for-agents">Cloudflare announcement</a></p>

<h2><span lang="zh-CN">LiteLLM LTS 接入 Seedream，并修复图像和 OCR 请求</span><span lang="en">LiteLLM LTS adds Seedream and fixes image and OCR requests</span></h2>

<p lang="zh-CN">11 月 26 日发布的 LiteLLM 1.108.19 LTS 接入了火山方舟 Seedream 的图像生成、编辑和定价支持。该版本也修复了 Gemini 未返回图像时仍给出计费的空 HTTP 200 响应的问题，以及 Azure Document Intelligence OCR 忽略页码和输出格式等参数的问题。<a href="https://github.com/BerriAI/litellm/releases/tag/v1.108.19">LiteLLM 发行说明</a></p>

<p lang="en">LiteLLM 1.108.19 LTS, released November 26, adds image generation, editing, and pricing support for Volcengine Ark Seedream. It also fixes a case where Gemini requests that produced no image returned a billed, empty HTTP 200 response, along with a bug that caused Azure Document Intelligence OCR to ignore options such as page selection and output format. <a href="https://github.com/BerriAI/litellm/releases/tag/v1.108.19">LiteLLM release notes</a></p>

<h2><span lang="zh-CN">Cline 调整模型目录并新增两家提供商</span><span lang="en">Cline refreshes its model catalog and adds two providers</span></h2>

<p lang="zh-CN">11 月 26 日发布的 Cline v4.1.28 从 OpenAI 提供商目录中移除了上游标记为弃用的模型 ID，包括 GPT-4o、GPT-4.1 和 o3。ChatGPT 订阅的模型列表也移除了 GPT-5.3-Codex-Spark。此次更新新增 Concentrate 和 Prima Labs 两家提供商。<a href="https://github.com/cline/cline/releases/tag/v4.1.28">Cline 发行说明</a></p>

<p lang="en">Cline v4.1.28, released November 26, removes model IDs marked deprecated upstream from its OpenAI provider catalog, including GPT-4o, GPT-4.1, and o3. The ChatGPT subscription catalog also drops GPT-5.3-Codex-Spark. The update adds Concentrate and Prima Labs as providers. <a href="https://github.com/cline/cline/releases/tag/v4.1.28">Cline release notes</a></p>

<h2><span lang="zh-CN">OpenHands 支持撤销团队会话共享</span><span lang="en">OpenHands lets users revoke conversation sharing with teams</span></h2>

<p lang="zh-CN">11 月 25 日发布的 OpenHands v1.46.0 支持列出已共享给团队组织的会话并撤销共享。自动化的 Git Sync 也新增一个开关，可将启用状态保留在本地。这两项改动均由 @hieptl 贡献。<a href="https://github.com/OpenHands/OpenHands/releases/tag/v1.46.0">OpenHands 发行说明</a></p>

<p lang="en">OpenHands v1.46.0, released November 25, lets users list conversations shared with a team organization and revoke that sharing. Git Sync for automations also gains a switch to keep activation status local. Both changes were contributed by @hieptl. <a href="https://github.com/OpenHands/OpenHands/releases/tag/v1.46.0">OpenHands release notes</a></p>
