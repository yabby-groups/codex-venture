<h2><span lang="zh-CN">Claude Code 将终端 Code Mode 扩展到四个云平台</span><span lang="en">Claude Code brings terminal Code Mode to four cloud platforms</span></h2>

<p lang="zh-CN">Claude Code v2.1.331 于 11 月 23 日发布。通过 Amazon Bedrock、Google Cloud Agent Platform、Microsoft Foundry 或 Claude Platform on AWS 使用 Claude Code 的团队，现在可以在终端会话中使用 Code Mode。<code>claude doctor</code> 也新增了 API 连通性检查，会显示 HTTP 状态、连接错误或未执行检查的原因。<a href="https://github.com/anthropics/claude-code/releases/tag/v2.1.331">发布说明</a></p>

<p lang="en">Claude Code v2.1.331 shipped on November 23. Teams using Claude Code through Amazon Bedrock, Google Cloud Agent Platform, Microsoft Foundry, or Claude Platform on AWS can now use Code Mode in terminal sessions. The <code>claude doctor</code> command also checks API connectivity and reports the HTTP status, connection error, or reason the check was skipped. <a href="https://github.com/anthropics/claude-code/releases/tag/v2.1.331">Release notes</a></p>

<h2><span lang="zh-CN">Codex 支持从终端历史打开会话</span><span lang="en">Codex opens saved sessions from terminal history</span></h2>

<p lang="zh-CN">Codex 0.172.0 于 11 月 24 日发布。用户可从搜索结果或会话记录打开已保存的对话和嵌套代理会话。由 @viyatb-oai 提交的修复让 <code>codex exec resume</code> 默认恢复保存的沙箱权限、工作目录和工作区根目录，显式传入的设置仍可覆盖这些值。<a href="https://github.com/openai/codex/releases/tag/rust-v0.172.0">发布说明</a></p>

<p lang="en">Codex 0.172.0 shipped on November 24. Users can open saved conversations and nested agent sessions from search results or transcripts. A fix contributed by @viyatb-oai makes <code>codex exec resume</code> restore saved sandbox permissions, the working directory, and workspace roots unless the caller explicitly overrides them. <a href="https://github.com/openai/codex/releases/tag/rust-v0.172.0">Release notes</a></p>

<h2><span lang="zh-CN">OpenAI Agents SDK 调整护栏检查与工具调度</span><span lang="en">OpenAI Agents SDK changes guardrail checks and tool scheduling</span></h2>

<p lang="zh-CN">OpenAI Agents SDK for Python 0.26.0 于 11 月 24 日发布。Realtime 输出护栏会在回合结束时执行检查。输入护栏拒绝请求后，SDK 会停止仍在排队的函数工具调用。新版也修复了代理交接时的脱敏处理，让 Session 历史保留脱敏结果。<a href="https://github.com/openai/openai-agents-python/releases/tag/v0.26.0">发布说明</a></p>

<p lang="en">The OpenAI Agents SDK for Python 0.26.0 shipped on November 24. Realtime output guardrails now run at turn completion, and the SDK stops queued function tool calls after an input guardrail rejects a request. The release also fixes handoff redaction so that redacted content stays redacted in Session history. <a href="https://github.com/openai/openai-agents-python/releases/tag/v0.26.0">Release notes</a></p>

<h2><span lang="zh-CN">Docling 转换停止时可取消排队的 PDF 解析</span><span lang="en">Docling cancels queued PDF parsing when conversions stop</span></h2>

<p lang="zh-CN">Docling v2.152.0 于 11 月 23 日发布。转换停止时，排队中的 PDF 解析任务可以取消，避免尚未开始的任务继续等待执行。新版还支持把音视频转录和幻灯片媒体组织为轨道，并为 Nemotron 3.5 Parse 增加了原生 MLX 支持。<a href="https://github.com/docling-project/docling/releases/tag/v2.152.0">发布说明</a></p>

<p lang="en">Docling v2.152.0 shipped on November 23. When a conversion stops, queued PDF parsing jobs can be canceled before they start. The release can also organize audio and video transcripts and slide media into tracks, and adds native MLX support for Nemotron 3.5 Parse. <a href="https://github.com/docling-project/docling/releases/tag/v2.152.0">Release notes</a></p>

<h2><span lang="zh-CN">Qwen Code 的 Web Shell 增加工作区产物库</span><span lang="en">Qwen Code adds a workspace artifact library to Web Shell</span></h2>

<p lang="zh-CN">Qwen Code v0.28.4 于 11 月 22 日发布。Web Shell 在本地守护进程模式下新增工作区产物库，扫描时会逐步显示结果。最近一轮被中断且需要继续的会话会在侧栏显示 Continue 标记，方便用户找到待续会话。<a href="https://github.com/QwenLM/qwen-code/releases/tag/v0.28.4">发布说明</a></p>

<p lang="en">Qwen Code v0.28.4 shipped on November 22. Web Shell now has a workspace artifact library in local daemon mode, with results appearing as the scan progresses. The sidebar also marks sessions that need to resume an interrupted turn with a Continue badge. <a href="https://github.com/QwenLM/qwen-code/releases/tag/v0.28.4">Release notes</a></p>
