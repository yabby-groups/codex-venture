# Codex Venture 视觉重构与验收

## 设计系统

原创红底 SVG 字母标识与系统字体字标构成横版品牌。首页以炭绿色头条、纸色背景和氧化红强调色区分阅读层级。深色主题使用独立的背景、文字和分隔线配色。系统字体负责中文与界面，Georgia 用于英文大标题，等宽字体用于日期和仓库数据。

CSS 变量集中在 `src/styles/site.css`。内容容器最大 1320 px，文章阅读宽度 760 px。850 px 以下收拢栏目导航，640 px 以下改为单栏正文和紧凑的次要头条网格。封面使用 16:9 作为可选比例，采用授权来源素材，正文图保留原始比例和图注。可复用 Astro 组件负责栏目标题、故事列表和仓库信息。

头条按现有发布时间选取最新独立报道。周报通过既有 ID 约定识别，原文章地址继续有效。GitHub 指标来自 2026-11-24 采集的 17 个 REST API 仓库快照，显示采集日期。仓库区按已展示项目的 Stars 排序，阅读热度暂无公开数据。未入库或未提供的仓库字段隐藏。

## 参考与视觉验收

读取了生产站的桌面及手机快照。The Verge 的主次稿件节奏、WIRED 和 MIT Technology Review 的编辑分区、Linear 的日期与发布层级、Hugging Face 的来源上下文、GitHub Trending 的项目元数据，以及 Hacker News 的列表密度均纳入参考。Vercel Blog 本次浏览器访问进入 Security Checkpoint。

Ego Lite Chromium 在本地静态预览覆盖 1920 × 1080、1440 × 900、1280 × 800、768 × 1024、390 × 844、360 × 800。验证矩阵包含首页、开源分类、最新资讯、普通文章、仓库文章、日报、周报、周报索引、搜索、归档、关于、统计及 404。1440 与 390 两组额外检查深色主题并保留截图。检查期间未发现页面级横向溢出。

## 测试与性能

- `npm run check` 通过，Astro 无错误或警告。
- `npm run build` 验证 106 个 HTML 页面及内部链接、元数据、RSS、Sitemap、Pagefind。Pagefind 收录 28 篇文章。
- `python3 -m unittest discover -s tests` 的 6 项测试通过。
- 浏览器实测 `本地`、`Codex`、`Handy` 和无匹配查询，验证双语标题、高亮、菜单键盘开关、主题跨刷新保留、Ctrl+K、新闻分页和周报目录。
- macOS 本机、390 × 844、关闭缓存、未限速的本地预览单次首页测量，LCP 296 ms，CLS 0.00061，load 321 ms。HTML 传输约 6.0 kB，CSS 约 4.1 kB，图标约 0.5 kB。此次交互未采到可报告的 INP。真实访问的 Core Web Vitals 和 WCAG 2.2 AA 全量符合性暂无完整证据。
